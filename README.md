# PLP Python Week 3 Assignment

This assignment practices loops, conditions, counting, totals, and debugging.

- grade_reporter.py - Uses a for loop and if/elif/else to calculate grades, pass and fail counts, and the average.
- bug_hunt.py - Fixes three bugs in a while loop program that calculates the sum of numbers from 1 to 5.

The hardest bug to find was the condition in the while loop because it did not produce an error message. I knew something was wrong because the program ran but printed 10 instead of the required answer 15.
